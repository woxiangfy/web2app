14. ⚠️⚠️ 悬浮窗三条**静默失败**修法：①Tauri 销毁必须 `destroy()` 不能 `close()`（Close 与 Alt+F4 同入口、被 `prevent_close+hide` 吞）；②Electron close 默认 `preventDefault` 转隐藏，而**「close 被 prevent」会取消 `app.quit()`** ⇒ 注入 `isQuitting` 放行；③冷启动副作用**不能复用** `applySettings(next,{persist:false})`（diff 恒 false）⇒ 用 `applyInitialSettings`（prev 固定 `DEFAULT_SETTINGS`，**托盘图标同样如此**）；④`hide` 必须清拖动标志。⚠️ 探针覆盖不到 ⇒ 真机四步见 `electron-app/AGENTS.md`。
15. ⚠️⚠️ **球真机 harness = `webview-app/src/floatprobe.rs`**（仅 Win，`--float-probe`；`inject_page_event` 注入 8 事件，**唯一跳过「球页 JS 把事件发出去」**）。铁律：①**条数只认结果文件的 `ALL PASS` 行**，别抄文档里的数字；②**探针模式必须跳过单实例插件与全局快捷键**（否则已有实例在跑 ⇒ 零输出 + 退出码 0 的**假绿**）；③**本机 `build()` 约 50% 永久挂死是环境抖动、不是产品缺陷**（换目录 / 换 UDF / 清 `msedgewebview2` 全无效）⇒ 用外部重试器，但重试器是**一次性产物、跑完常不在工作区**（故不指路径），自建时用 .NET `WaitForExit(ms)` 取码。退出码 `0`/`>0`/`97` 环境/`98` 看门狗。⚠️⚠️ 失败收尾的 `labels` 是**分诊金钥匙**（`["float","main"]` = build 其实成功、只是没等到可见 ⇒「窗口不存在」≠「build 失败」）；判「是不是我的改动」先看失败点相对改动点的位置。⚠️⚠️ **某步从「复用」改「重建」⇒ 所有下游等待都要重论证**（v1.76 右键改销毁后固定 `sleep(700)` 必然赶不上 ⇒ 改轮询；连带 `WATCHDOG_SECS` 240→330、`BUILD_WAIT` 120→**180**）。⚠️ 假主窗漏 `data_directory` ⇒ 建窗 9ms 退化到 60s+ 挂死。
16. ⚠️ 球实测：`GetWindowRgnBox` **含端**（`[0,70)²`→`(0,0,69,69)`）—— 那是 **v1.77b–v1.79 的历史取值**，v1.80 起球窗**不设任何窗口区域**、断言已反转为「必须为空」；`monitor_from_point` 用 **`MONITOR_DEFAULTTONULL`**（测试点须放显示器**内**）；**WebView2 UDF = `%LOCALAPPDATA%\com.example.web2app\EBWebView`，与 exe 目录无关**。⚠️ `tabs.rs::create_host_window` 曾漏 `data_directory`（v1.72 修）⇒ **同一不变量在多处实现必须逐处核对**。
17. ⚠️⚠️ **「视觉 / 命中」两壳格局（v1.80 重排）**：**Tauri 侧 `CreateEllipticRgn` / `SetWindowRgn` 已全删**（v1.71–v1.79 的「窗口区域 ∥ Electron `setShape`」同构格局作废）。现行**两壳视觉都靠 `WS_EX_NOREDIRECTIONBITMAP` + DirectComposition 真逐像素 alpha**（Tauri 需 tauri 2.12.1 / wry 0.57；球窗 `transparent(true)` + `no_redirection_bitmap(true)`），**命中各自独立** —— Tauri `install_circle_hit_test`（`EnumChildWindows` 递归父窗 + WebView2 子窗 → `SetWindowLongPtrW(GWLP_WNDPROC)` 幂等子类化，只拦 `WM_NCHITTEST`：圆内 `HTCLIENT`、圆外 `HTTRANSPARENT`，`WM_NCDESTROY` 还原，圆心/半径存静态原子量、`0` = 未初始化 fail-open），Electron 仍 `win.setShape`（`@experimental` ⇒ **必须 try/catch 降级**）。**共同语义：都只管命中、都不裁视觉**。页面侧 **250ms 双击去抖**。⚠️ 探针**只能取证、不能当 CI 门禁**，且**即便全绿也不覆盖渲染**（渲染需普通桌面会话；受限会话 `msedgewebview2.exe` 进程数恒 0）。
18. ⚠️⚠️ **「关窗 = 退出」被主窗之外的存活窗口改写**（球的独立窗 / 页签窗都挡住 `window-all-closed`）⇒ 必须显式写「驻留理由」`(tray && min) || (win && float_enabled)`（v1.75，两壳同语义；Tauri 用 `cfg!` **布尔** —— `#[cfg]` 分叉会让非 Win 的 `float_icon` 变未使用变量 ⇒ `-D warnings` 编译失败）。⚠️ **没启用托盘时托盘的「退出」不存在** ⇒ 设置页必须有「退出程序」= `quit_app`（Tauri `app.exit(0)` / Electron `requestQuit`：先置 `quitting` 再 `app.quit()`；**四处同改**：HTML 字面量 / ALLOWED / `tauri:` 处理器 / 入口接线，`smoke.ts` 命令清单也要有）。⚠️ 守卫**必须限定在被测块内**（`runtimeSettings.float_enabled` 在启动日志里也出现 ⇒ 全文 `includes` 是自我满足的假守卫）。
19. ⚠️⚠️ **球页不得挂原生提示（`title`）**：球窗 always-on-top，而原生提示条是**独立非置顶窗口** ⇒ 只会被画在球窗**之后**、从透明环带漏出浅色残片；球窗仅 56 逻辑宽 ⇒ **结构性不可用** ⇒ 改 `role="button"` + `aria-label`（操作说明由设置页承载）。守卫 `contract_tests::float_ball_has_no_native_tooltip` + Electron `float-contract.test.ts`。⚠️ **取证范式**：Electron 复刻**同一份** `floaticon.html` + 真实鼠标 `SetCursorPos` + `PIL.ImageGrab` 做「hover / 移开 / 再 hover」三态对照 ⇒ **差异 bbox 即 hover 专属元素**。
20. ⚠️⚠️ **球窗「真不进任务栏」= `show_ball()` 是唯一显示入口**（v1.77）：`.skip_taskbar(true)` **不够** —— tao 按「窗口无父」置 `ON_TASKBAR` ⇒ 建窗写死 `WS_EX_APPWINDOW`，`DeleteTab` 又在 `visible(false)` 时调。⚠️⚠️ **顺序硬要求：`show() → unminimize() → apply_ball_window_styles() → delete_taskbar_tab()`** —— tao `apply_diff` 在显示路径用**缓存标志整体重写 `GWL_EXSTYLE`** ⇒ 写在 `show()` **之前等于没改**（v1.72 的 `NOACTIVATE` 因此一直没生效）⇒ **通用范式：手改 `GWL_EXSTYLE` 必须在每次 `show()` / `unminimize()` 之后重补 + 读回校验**（`SetWindowLongPtrW` 失败只回报 0，而 0 也是合法旧值）。球窗另置 `.title("")`，读回 `0x8000198`。守卫 ⑥b / ⑥c。⚠️ `ITaskbarList` **任何方法前必须先 `HrInit()`**（否则 `DeleteTab` 返 `E_FAIL` 且什么都不做 —— v1.77 漏了还用 `let _ =` 吞掉）。
21. ⚠️⚠️ **不变量：「球 `#w2f-ball` == 活柱 == 命中圆」严格等大**（v1.77b 立，v1.80 换地基后语义不变）：不等大就有**错位带** —— 「看着是桌面、点下去被球吃掉」或「看得见球、点下去穿透」⇒ **球内元素禁 `transform: scale()`**、**半隐藏态禁 `opacity`**，反馈一律 `filter: brightness()`。守卫 `contract_tests::float_page_ball_fills_the_live_pillar` + Electron 同源。
22. ⚠️⚠️ **「视觉地基错了，几何怎么调都救不回来」**（v1.77b→v1.79 三案总结）：球缘「浅色异形 / 锯齿」的真因是**窗口只有 1bit 区域掩码（或页面绕路自绘黑底），本身没有逐像素 alpha** —— 三案只在同一条思路里改症状形状。**正解 = 换地基**：v1.80 升 **tauri 2.12.1 / wry 0.57.0 / tao 0.37.1 / webview2-com 0.39.1 / windows 0.62.2**（约束写 `0.37`/`0.57`/`0.39`/`0.62`，精确值看 `Cargo.lock`）+ 球窗 `no_redirection_bitmap(true)`、**删全部区域 API**、页面恢复真透明（Rust 与页面都不得再含壳标记 `data-w2f-shell`）。⇒ 通用判据：**症状落在「边缘质量」上时，先问「合成链路有没有逐像素 alpha」，再谈几何**。⚠️ **升级依赖不是禁区，但「文档说有」不算数、必须读 crate 源码**：tao 0.35 只在 `NO_BACK_BUFFER` 才加 `WS_EX_NOREDIRECTIONBITMAP`，tauri-runtime-wry **2.11.4 完全不透传** `no_redirection_bitmap`（2.12.1 才透传）⇒ **能力没透传时上层怎么写都无效**；代价是必须逐项复验 WebView2 钩子。
