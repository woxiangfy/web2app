## 顶部通栏按钮悬停优化 + inject 资源保护（两条需求）

### 1. 顶部通栏按钮悬停效果优化
- `webview-app/src/titlebar.js`：`.w2t-btn` 的 `cursor:default` → `cursor:pointer`；新增纯 CSS tooltip（`::after` + `data-tip`）替代原生 `title`（原生有 1~2s 延迟、样式随系统、暗色看不清）。按钮 HTML 的 `title=` 全部改 `data-tip=`。tooltip 带 `transition-delay` 防扫过时疯狂闪现；`pointer-events:none` 不挡拖动/点击；伪元素内容走 adoptedStyleSheets，不触达 CSP。
- `webview-app/src/shell.html`（多页签标签栏）：`.win-btn`/`.nav-btn` 加同样的 `data-tip` tooltip（它们本来就是 `cursor:pointer`，只补 tooltip）。
- ⚠️ 探针按 className + 几何断言按钮，**不依赖 `title` 属性** ⇒ 改 `title`→`data-tip` 安全。

### 2. 保护 resources/inject 下的注入资源
- 背景：`titlebar.js`/`loading.js`/`splash.html`/`shell.html`/`settings.html` 原本经 electron-builder 的 `extraResources` 放到 `resources/inject/`（asar 外，明文可改），与 config.json 之前的问题同类。
- 方案：与 config.json 同待遇，改随 asar 分发：
  - `scripts/stage-assets.cjs`：新增第 3 步，把这些文件拷贝到 `out/inject/`；任一缺失即 `process.exit(1)`（不静默）。
  - `electron-builder.yml`：删除 extraResources 里 inject 相关条目（只留 icons + sidecar）；`files` 注释同步。
  - `index.ts::injectDir()`：`app.isPackaged ? join(app.getAppPath(),'out','inject') : webview-app/src`。
  - `settings-window.ts::locateSettingsHtml()`：同用 `app.isPackaged` 分叉；移除 `resourcesPath` 参数（连带 `readSettingsHtml` 签名简化）。
  - `scripts/check-asar-config.cjs`：护栏扩展，同时校验 `out/inject/*` 5 个文件进 asar。
  - 两处 CI workflow 的 step 名/注释同步（electron-ci.yml + electron-build-custom.yml）。
- ⚠️⚠️ 关键教训：`injectDir()`/`locateSettingsHtml()` 必须用 **`app.isPackaged`** 区分，**不能**用 `existsSync` —— stage 也会在开发目录生成 `out/inject/`，按「存在即打包副本」判会让开发态误读 stage 副本、破坏单一真源（configRoot 早就是 isPackaged 分叉，这里对齐）。
