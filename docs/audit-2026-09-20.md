## 0. 摘要

本轮把「文档 / 实现 / 门禁」三者之间对不上的地方做了一次闭环。**最重要的一条**：CI 里挂着
`cargo fmt --all -- --check` 这一**阻断**门禁，而本机代码树**早就是红的**（5 处违规）——即
「CI 一旦跑起来，第一个作业就会失败」，此前多轮只跑 clippy + test 从未发现。

| 门禁 | 改前 | 改后 |
|---|---|---|
| `cargo fmt --all -- --check` | **1（红）** | **0** |
| `cargo clippy --all-targets -- -D warnings` | 0 | 0 |
| `cargo test --all` | 0 | 0（46 + 13 + 7 + 13 项全过） |
| `pnpm run typecheck` / `build` | 0 / 0 | 0 / 0 |
| `pnpm run probe`（单窗口） | 112/112 | **112/112** |
| `pnpm run probe --tabs`（多页签） | 23/23 | **23/23** |
| `pnpm run smoke` | 0 | 0 |

> 注：`--probe` / `--smoke` 均在无 GPU 沙箱下以 `--no-sandbox --in-process-gpu` 运行，退出码即结论。

## 3. 遗留事项（按优先级）

1. **Tauri 侧落盘日志**：Electron 已有 `startup-log.ts`，Tauri 侧仍只有 stderr（GUI 程序等于没有）；
   定了这个机制，B4 的三处静默失败才有地方报。
2. **`electron-app/tests/` 人工清理**：删 96MB 便携版副本与 10 个探针日志（沙箱禁止删除，需人工执行）；`.gitignore` 已就位。
3. **测试缺口补齐**：`proxy-server/src/main.rs` 的握手 JSON 契约、`tabs.rs::resolve_popup_url` —— 双壳接口面中唯一没有断言的地方。
4. **依赖与 lint 卫生**：清 `http-body-util`（两处）、`Win32_System_WinRT`、`bytes` 降 dev-dep；收窄 `#![allow(dead_code)]`。
5. **功能缺口（沿用既有排期）**：M4 下载接管 / 右键菜单 / F12；M7 CI。
