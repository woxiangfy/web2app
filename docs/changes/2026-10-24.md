## 1. 批次①：settings.json 读-改-写统一入口 `updateDocument`

`settings.json` 三段（设置 / `window` 主窗几何 / `float_window` 悬浮球几何）共居一个
文件后有三个写入方，此前各写各的序列化。本批把「读-改-写」收敛为唯一入口
[`updateDocument(loc, patch)`](../../electron-app/src/main/settings.ts)：

- patch 里**出现**的键整体替换、**缺省**的键原样保留（不是深合并，语义是「只改我这段」）；
- `saveSettings` / `window-state.ts::saveWindowState` / `float-window.ts::persistGeometry`
  三个薄封装全部收敛到它；
- 新增 [test/settings.test.ts](../../electron-app/test/settings.test.ts) 5 用例钉住
  三段互不覆盖 + 键序（设置四键 → window → float_window）+ 原子写无 tmp 残留。

## 2. 批次②：index.ts 装配化（职责边界拆分）

入口文件只保留装配，决策逻辑下沉为可测模块（均零 Electron 运行时依赖或薄依赖）：

| 新模块 | 职责 |
|---|---|
| `src/main/navigation.ts` | `createNavigator`：resolveAndCache 只读缓存、bootstrap 导航代际（navSeq）、retryFromSplash / autoBootFromSplash |
| `src/main/lifecycle.ts` | `closeResidency(settings, platform)` 关窗驻留判据（reasons 顺序「托盘 → 悬浮图标」，`join(' + ')` 复现日志原文） |
| `src/main/tab-spawn.ts` | `makeTabSpawn` 页签开窗决策 |
| `src/main/startup-log.ts` | 新增 `printStartupSummary`（启动信息打印收敛） |

守卫同步（强度不降的「两半」手法）：`float-contract.test.ts` 的 v1.75 关窗驻留钉子改为
「index.ts 钉接线（`closeResidency(runtimeSettings, process.platform)` + hide 分支）+
lifecycle.ts 钉判据（两条驻留理由 + `reasons.length > 0 ? 'hide' : 'quit'`）」，避免
重构后原「close 块内联判据」形式失配变成假守卫。

## 3. 批次③：probe-single.ts 段函数化（探针行为零变化）

单窗探针 `runProbe` 由 1600+ 行巨型函数拆为 **19 个具名段函数**
（`probeSec00Splash` … `probeSec17CloseButton`，含 `91SettingsGear`），`runProbe` 缩为
按序 `await probeSecXX(...)` 的编排层；跨段共享状态（nav / snap 闭包、快照槽 `s`、
fwd / side / HK / clickBtn / wc）改为**显式传参**（7 段不收 ctx，`noUnusedParameters` 过）。

约束兑现（探针断言一条不改、文案不改、150 条数字不变）：

- 全部 `p.check(` / `p.near(` 断言行做**多重集逐字比对**：拆分前后 151 行 vs 151 行完全一致
  （PowerShell `Compare-Object` 验证）；
- `--probe` 149/150 与基线一致、`--probe --tabs` 47/47；
- 每段都「先 `s = await snap()` 再读快照」，传参无旧值风险。

## 4. 批次④：设置页命令名三方一致守卫

`float-contract.test.ts` 新增测试「invoke 字面量 ⊆ 垫片 ALLOWED ⊆ 主进程处理器（六命令
全量）」：从 `settings.html` 抽 `invoke("...")` 字面量、从 `settings-preload.ts` 抽
ALLOWED 白名单、从 `settings-window.ts` 抽 `ipcMain.handle('tauri:...')`，断言六命令
（get_settings / save_settings / close_settings_window / clear_web_data /
show_float_window / quit_app）全量在场 + 子集契约两方向；三处各自带 ≥6 的下限断言，
防正则失配退化成假守卫。

## 5. 批次⑤：复用性 / 依赖方向收口

### 5.1 P2-5 工具函数收敛到 `src/main/util.ts`

`toStr` / `sanitizeDirName`（含 `RUST_WHITESPACE_RUN` 白空集）/ `nearestKey` /
`editDistance` 从 `config.ts` 抽出（原 doc 注释逐字搬移），`settings.ts` / `index.ts` /
`config.test.ts` 改从 `util.ts` 导入；`config.ts` 纯删 63 行。
⚠️ `config.ts` 行尾**混用**（587 CRLF + 5 LF）⇒ 搬移用临时脚本按行区间**逐字节**提取、
token 级保留每行原始终止符，禁止 split/join 归一化（否则整文件 diff）。

`node --test` 直跑 TS 的 resolve 钩子（补 src 内部无扩展名相对导入的 `.ts`）从
`settings.test.ts` 内联收敛到 [test/ts-resolver.mjs](../../electron-app/test/ts-resolver.mjs)，
由 `pnpm run unit` 经 `--import` 预载（钩子必须先于被测模块的导入图解析，不能写在测试文件内）。

### 5.2 P2-8 protocols.ts 反向依赖收口

`protocols.ts`（底层协议分发）此前反向 import `settings-window.ts` 的 `FALLBACK_HTML`。
改为 `ProtocolDeps` 增 `fallbackHtml: string`，资源本体留在 `settings-window.ts`，
由 `index.ts` 注入 —— 依赖方向恢复为「入口 → 各模块」单向。

### 5.3 P2-4 悬浮球吸附 / 拖动决策纯函数化

`float-window.ts` 两处决策块抽到 [float-layout.ts](../../electron-app/src/main/float-layout.ts)：

- `planDrop(b, mon, snap)` —— 松手落点决策（吸附贴边 / 自由态钳回），自 `onDragEnd` 抽出；
- `planPeekCollapse(edge, mon, winY, cursor)` —— 悬停延迟到期缩回决策（光标在缩回后
  矩形内则不缩），自 `finishPeekLeave` 抽出。

IPC / 窗口生命周期一行未动（anchor / press 时序、close 语义、建窗 / 销毁均保持）；
`float-contract.test.ts` 两条源码钉子按「两半」手法同步（planDrop / planPeekCollapse
内部判据 + float-window 接线），强度不降；`float-layout.test.ts` 新增 2 组单测
（吸附 / 自由 / 屏外钳回 / 多屏负原点 / snap 容差；光标半开区间 / 左右镜像 / y 越界钳回）。

⚠️ **真机目视清单无法自动化**：吸附贴边手感、拖动跟手、悬停展开 / 缩回时机、双击去抖、
右键关功能等只有真机能验（`electron-app/docs/float-ball.md` 的真机目视清单），本次重构
只把几何决策纳入单测，真机项仍按既有清单人工验证，不做自动化伪装。
