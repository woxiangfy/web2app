## 四、优化批次④（P4）三大文件垂直拆分（零行为变更纯代码搬家）

对象：`floatwin.rs`（1,656 行）、`tabs.rs`（1,375 行）、`proxy.rs`（1,411 行），各拆为根文件 +
`src/xxx/` 子目录子模块。口径同 P1-a：不改逻辑 / 签名 / 符号名；原模块内私有条目收口
`pub(super)`（有效可见范围不变）；对外路径经根文件重导出保持 `crate::xxx::*` 不变。

### 1. 拆分布局

| 原文件 | 根文件（拆后） | 子模块（行数） |
| --- | --- | --- |
| `floatwin.rs` 1,656 | 575 行（docs / 常量 / FloatState / 协议 / persist / 几何纯函数） | `floatwin/{events 425, shape 206, window 349, tests 140}` |
| `tabs.rs` 1,375 | 66 行（docs / HOST_LABEL 重导出 / 转发） | `tabs/{state 102, window 817, ipc 208, tests 242}` |
| `proxy.rs` 1,411 | 358 行（docs / ProxyState / start_proxy / proxy_handler） | `proxy/{auth 147, ws 164, headers 99, tests 692}` |

- 根文件对子模块：`mod` 声明 + 私有 glob（`use xxx::*;` 供内部互访）+ 显式 `pub(crate) use` /
  `pub use` 重导出（保对外路径；proxy 对 sidecar 是 `pub use`）。
- `#[tauri::command]` 的隐藏宏坑：命令函数拆入子模块后，`generate_handler![tabs::xxx]` 还需经
  根文件重导出 `__cmd__*` 与 `__tauri_command_name_*` 两个隐藏宏，否则 E0603 / 私有宏导入。
- **`proxy.rs` 子模块声明必须带显式 `#[path = "proxy/xxx.rs"]`**：本文件是 sidecar
  （`crates/proxy-server`）经 `#[path]` 复用的单一真源，`#[path]` 加载的模块里裸 `mod auth;`
  会按【本文件所在目录】（`src/`）找文件（sidecar 报 E0583），而 `#[path]` 相对本文件目录解析，
  两 crate 同源同路径。proxy-server 一字未动，`w2a-proxy` 32 测试全过。
- `random_hex_token` 重导出在 sidecar 侧未用（主 crate tabs / floatwin 用），定点
  `#[allow(unused_imports)]`，不放宽其它 import 告警。

### 2. 契约守卫跟随（零删测、覆盖面不减）
