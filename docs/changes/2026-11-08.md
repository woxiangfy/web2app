# 2026-11-08

## webview-app：唤醒快捷键判据与 Electron 对齐 + 旧配置回退提示（用户可见行为变更）

**动因**：设置页是双壳共用（`dist/settings.html`，Electron 经 `stage-assets.cjs` 复制），但**主进程校验两侧不同**：
Electron `hotkey.ts::hotkeyProblem` 有五条判据，Tauri 只有「`Code::from_str` 可解析 + 不与 `Shift+F1` 冲突」两条。
后果：Tauri 侧可把裸 `F9` 注册成全局键（占满该键、用户在别处打不了字），也会尝试注册 `Ctrl+Space`
（中文 Windows 输入法切换）这类系统占用组合，表现是「保存成功但按下去没反应」。

### 判据集（最终，两壳同一套、同一顺序）

1. **未设置**（主键为空）→ 合法；
2. **裸单键**（Ctrl / Alt / Shift 一个都没勾）→ 拒绝；
3. **系统占用键** → 拒绝（7 个）：`Alt+Tab`、`Alt+Space`、`Alt+F4`、`Alt+Escape`、`Ctrl+Escape`、
   `Ctrl+Space`、`Ctrl+Alt+Delete`；
4. **`Shift+F1`** → 拒绝（固定用于打开设置）；
5. **无法映射的键** → 拒绝：只接受 `KeyA–Z`、`Digit0–9`、`Numpad0–9`、
   `NumpadDecimal/Add/Subtract/Multiply/Divide`、`F1–F24`、`Space/Enter/Escape/Tab/Backspace/Delete/
   Insert/Home/End/PageUp/PageDown/↑↓←→` 与 `Minus/Equal/BracketLeft/BracketRight/Backslash/Semicolon/
   Quote/Comma/Period/Slash/Backquote`（与 Electron `CODE_TO_KEY` 同一套键集）。

实现在 `src/settings.rs::hotkey_problem`（纯函数，无平台依赖），**同一函数**用于两处：
`save_settings` 保存前第二道（页面之外）、`load_settings` 启动回退。

### 哪些旧配置从此不再接受（行为变更）

旧 `settings.json` 里以下组合**从本次起不再注册**：

- 任意**裸单键**（`F9`、`Escape`、`Digit0`、`KeyA` …，无任何修饰键）——Tauri 之前会直接注册；
- 上表 **7 个系统占用组合**——Tauri 之前会尝试注册（多数被系统抢走，等于静默失效）；
- **`Shift+F1`**（两侧本来都拒，无变化）；
- **Electron `CODE_TO_KEY` 之外的键**：`CapsLock`、`IntlRo`、`MediaPlayPause`、`MetaLeft`、`F25` 等
  （Tauri 的 `Code::from_str` 认得它们，Electron accelerator 映射不认得 ⇒ 现在统一按「不支持」拒）。

### 旧配置回退的表现（不静默）

- 启动时若磁盘上的 `wake_hotkey` 被判非法：**按「不设置」处理**（不注册全局快捷键），
  `settings.json` **原文件不改写**（保留现场，便于用户核对）；
- 设置页快捷键卡片的**状态行**显示「旧配置里的唤醒快捷键 X 不再被接受：<原因>。已回退为「不设置」
  （配置文件未改动）；重新设置并保存后本条提示消失」；
- 提示只是**进程内状态**：`Settings::hotkey_notice` 带 `#[serde(skip)]`（不写盘），由 `get_settings`
  返回的 `SettingsView`（`#[serde(flatten)]` 保持原字段形状）单独下发；用户**重新保存成功后**
  页面 `loadNotice` 归零、后端 state 换成了页面载荷（该字段默认空）⇒ 提示消失，重启不再出现；
- 页面渲染优先级：草稿错误 > 待保存 > 旧配置提示 > 常规状态（正在拼新组合时优先说「待保存」）。

### 风险与回退

- 设置页（两壳共用）**仍不检查第 5 条**（页面无法知道 accelerator 键集）：捕获到 `CapsLock` 这类键会在
  **保存时**被主进程拒绝，提示文案「不支持的按键」——与 Electron 现有表现一致，不是新差异。
- Android 无全局快捷键，`hotkey_problem` 只在桌面端保存路径使用；启动回退在移动端无副作用（不注册）。
- 若需撤回：还原 `settings.rs` / `dist/settings.html` / 契约测试三处即可，`settings.json` 结构未变
  （新字段 `#[serde(skip)]` 不落盘），旧配置无需迁移。
