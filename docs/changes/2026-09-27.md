## v1.36（2026-09-27）

**第四轮三类清单审计闭环（无外部输入，模糊项按通用默认补全）**：①**不足**——修「首个页签失败重试」的空白壳回归：`spawnFirstTab` 原先在**发起重试前**就撤掉失败遮罩，而重试是异步的（sidecar 解析可能数秒）⇒ 用户对着空白壳干等，正是该遮罩要消灭的失败形态；改为**仅成功时撤**，重试期间保留遮罩（按钮已切「重试中…」并置灰）提供持续反馈；②**冗余**——失败遮罩的 `top` 写死 `38px`、文案写死「32 个上限」，与 `TAB_BAR_HEIGHT` / `MAX_TABS` 三处同值可漂移（改栏高会让遮罩盖住标签栏）；改为从 `tabs.ts` 插值同源；③**缺失/过期**——根 README 变更表按版本升序排列，而 `v1.35`(09-26) 被误插在 `v1.34`(09-25) **之前**，读者会把 v1.34 当成更新的一版；两行对调恢复升序；④门禁复测：Electron `typecheck` 通过、`unit` **35/35** 全绿（本轮未触碰 Rust 侧与探针断言）
