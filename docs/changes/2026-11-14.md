## Android 优化清单（`docs/android-improvements.md`）重新审查与推进：6 项落地、4 项转待决策

**动因**：清单自 2026-10-14 起停在「P0/P1 已实施、P2 全部待办」，#9–#19 共 11 项从未推进。
本次逐项重审，按「能否本机验证 + 是否改变产品语义」分成两类：小问题直接落地并记录，
会改语义/分发的转 §5 待决策（附选项与建议）。

**口径**：本机无 Android SDK/NDK，因此只做到「静态契约 + 纯逻辑单测 + 补丁链按序试打」；
需真机的行为一律留在 §4 清单，不以「测试绿」代替「功能已验」。

### 已实施

1. **#9 返回键先关浮层**（`patch-android-back.py` + `mobilebar/core.js`）
   `handleOnBackPressed` 先 `evaluateJavascript` 问页面 `window.__web2appMobileBar.closeSheet()`，
   返回 `1` 即消费本次返回；否则走 `web2appBack()`。
   ⚠️ eval 串必须返回**数字**：`evaluateJavascript` 回调会把字符串再包一层引号，`r == "1"` 永不成立。
2. **#10 无历史时「再按一次退出」**（同一脚本）
   不再立即 `finish()`：首次只 Toast「再按一次退出」，2s 内第二次才退出（`web2appLastBackAt`）。
3. **#11 页签切换文案明示**（`mobilebar/tabs.js`）
   面板「新建标签」下新增 `.w2m-hint`：「切换标签会重新加载页面（移动端同时只保留一个页面）」。
   只做文案、不做状态快照（单 webview 下序列化成本与收益不对等，已在 §5 记为不建议做）。
4. **#12 软键盘让位**（`mobilebar/bottom_space.js::installKeyboardAvoid`）
   `visualViewport` 与 `innerHeight` 差值 ≥ 60px 时把底栏 inline `bottom` 抬到键盘上沿；
   `adjustResize` 模式差值为 0，天然无操作。不动 body 的底部让位契约。
5. **#15 代理模式探测真实上游**（`bootstrap.rs`）
   新增 `probe_target`：代理 + 上游 origin 已知 → 探上游并标记 `via_proxy`；否则退回导航地址。
   新增 `probe_auth_message`：代理模式下 401/403 单独成类（「上游可达但鉴权未通过」），
   不再把用户引去查 WebView 内核。`probe_ok_message` 增加 `via_proxy` 措辞。
6. **#16 宽屏底栏限宽居中**（`mobilebar/core.js`）
   `@media (min-width:600px)`：底栏与面板 `max-width:560px` + `left:50%` + `translateX(-50%)`。
   `syncBarWidth` 仍钉 `innerWidth`，由 `max-width` 收口 —— 刻意不改 JS，少一处状态少一类不同步。
7. **#18 明文流量开关**（新增 `.github/scripts/patch-android-cleartext.py`）
   生成 `res/xml/network_security_config.xml`，Manifest 的 `usesCleartextTraffic` 换成
   `networkSecurityConfig`；两个 workflow 的全局 sed 步骤删除，改为调用该脚本（策略单一落点）。
   **首版收紧为「仅 `127.0.0.1`/`localhost`」，当日按产品要求回退为全放行**：目标站点大量只有
   http，禁明文会让直连被系统拦下（`ERR_CLEARTEXT_NOT_PERMITTED`）。脚本注释与清单均已写明
   「日后重新收紧必须保留回环例外」。

### 暂缓（转 §5 待决策，附选项与建议）

- **#13 暗色启动底色**：Web 层已有 `prefers-color-scheme` 分支；缺的是首帧前的
  `nav::SPLASH_BG`（编译期常量）。建议走 `values-night` 主题 + Android 去掉窗口 `background_color`。
- **#14 DNS 解析结果持久化**：涉及「远端可控」的安全语义、失效回退与竞态、可见性三个问题。
- **#17 移动页签跨启动持久化**：恢复出的记录并未加载，与 #11 文案预期冲突。
- **#19 x86_64 / universal / AAB**：体积、CI 时间与分发渠道（GitHub Release 直发 APK）取舍。
