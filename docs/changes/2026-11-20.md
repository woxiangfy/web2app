# 2026-11-20 变更记录

## Android 底栏：面板精简 + 底部遮挡修复

### 需求（用户真机反馈，附截图）

1. 「更多」面板只保留 **清除浏览数据** 与 **退出应用**，其余全部去掉，**也不显示链接地址**；
2. 「列表」面板不要「＋ 新建标签」，「切换标签会重新加载页面（…）」提示也去掉；
3. 底部存在内容被底栏遮挡的情况（列表页滚到底，最后一行仍被压在底栏下面）。

### 改动

**一、`more.js` 面板精简为两行**

- 删除地址头（`.w2m-morehead`）与 刷新 / 复制链接 / 分享 / 在浏览器打开 四行，连同
  `copyCurrentLink` / `legacyCopy` 与 `ICO_REFRESH` / `ICO_COPY` / `ICO_SHARE` /
  `ICO_EXTERNAL` 四个图标、`.w2m-morehead` 样式一并移除；
- 保留：清除浏览数据（两步确认 + 3s 撤防）/ 退出应用，均照旧走 `__web2appAndroid` 桥
  （一次性密钥 + 主框架门控）；
- Kotlin 桥 `patch-android-extras.py` 的 `share` / `openBrowser` 方法**保留为预留能力**，
  仅下线 UI 入口（桥面契约测试 ④d 不动）。

**二、`tabs.js` 列表面板去掉「＋ 新建标签」与切换重载提示**

- 删除 `.w2m-newrow` 行与 `.w2m-hint` 说明行；「切换 = 按记录地址重载」的行为本身未变；
- 新建页签从此只剩网页 `target=_blank` / `window.open` 一条路（`web2app:open-tab`）。

**三、`web2app:new-tab` 事件链一并移除（UI 入口没了，事件即死链）**

- JS 侧不再 emit；Rust 侧移除 `NEW_TAB_EVENT` 常量、`app.listen` 监听、`create_tab()`、
  仅供它使用的 `home_url()`；`MTab::new_tab`（状态机压栈）保留，由
  `create_tab_with_url` 消费。

**四、底部遮挡修复（`bottom_space.js` + `mount.js`）**

真机症状：页面自己的「顶部有头 + 自滚动内容区」布局（内嵌滚动区底边贴到视口底），
滚到底最后一行仍被底栏压住。既有两条机制都罩不住：

- `body` 契约只管文档级滚动，管不到页面自己的滚动容器；
- shrink 判据要求「高度 ≈ 视口高」，带头部的自滚动区（如 `calc(100vh - 60px)`）认不出。

两层修法：

1. **内嵌滚动区 / 子文档让位**：`applyChromeFit` 新增「压盖带」判定（元素底边落在
   视口底 − 一格 .. 视口底 + 2 之间），命中者只认「真会滚」的容器（`overflow-y:auto/scroll`）
   与 `iframe/object/embed`（普通块级元素滚动途中底边扫过压盖带，不动）。命中后
   `padding-bottom: 一格`（页面原有 px 内边距叠加保留，同 `shiftedBottom` 思路）——
   滚到底时内容停在底栏上沿；对 iframe 这一招还把内嵌视口缩到预留之上，比减高度更普适。
   独立标记 `data-web2app-mobile-pad`。
2. **滚动根契约探测补跑自愈**：首探早于页面样式落定时会「假绿」（探测绿了不再复查，
   页面样式随后盖掉契约 CSS ⇒ 底部被压）或「假红」（body 未布局量到 0 ⇒ 过早落退路，
   且 inline `!important` 永久压住样式表）。退路改为成对可撤销
   （`applyScrollFallback` / `undoScrollFallback`），`installScrollRootRecheck` 在
   `load` + 1.5s + 3s 各补探一次：绿则撤退路、红则落/保持退路，两条错路都能回头。

### 测试与契约

- `mobile_bar_contract.rs` 同步：① 事件对去掉 new-tab；④b/④c 改钉两行菜单并加**反例锁定**
  （`moreRow(ICO_REFRESH` 等四个旧行、`.w2m-morehead`、`copyCurrentLink` 出现即红灯）；
  ⑤b 加反例（`w2m-newrow` / `'web2app:new-tab'` 不得再现）；原 ⑱（切换重载提示）随提示
  下线删除；新增 **⑥b `bottom_occlusion_self_heals`**（内嵌滚动区让位 + 探测补跑/退路可撤销）。
- `mobilebar/tests.rs`：`event_names` 去掉 `NEW_TAB_EVENT` 断言并注记下线原因。
- `cargo test --all` **338 passed / 6 ignored**（删 ⑱ 加 ⑥b，总数不变）、`fmt` / `clippy`
  ✅；mobilebar 五片拼接后 `node --check` 语法 ✅。
- 反向对照：契约测试的反例断言即为反向对照（把下线行加回代码即 FAIL）。
- ⚠️ 待真机复验：清单 `webview-app/docs/android.md` #4–#7（面板两行）、#12（无新建/提示）、
  **#16（新增：自滚动区滚到底不被压）**。
