### 4.2 失败归因（本轮唯一的「异常输出」）

`cargo clippy` 的输出里有 14 行 `warning: error deleting lock file for incremental compilation
session directory … 拒绝访问。 (os error 5)` 与若干 `generated 1 warning`。

- **归因**：Windows 下 cargo 清理 `target/debug/incremental` 锁文件失败（当时 `pnpm run probe`
  正在并发跑 `cargo build --release` 编 sidecar，target 目录有竞争），属**环境噪声**，不是代码告警。
- **确证方式**：`cargo clippy … -D warnings 2>&1 | grep -E "^error"` ⇒ 输出为空（`NO_REAL_ERRORS`），
  且末尾正常 `Finished`。若当时把 `generated 1 warning` 当成真告警，会得出「改了代码就出警告」的错误结论。
