# 悬浮球根治方案（最终版，2026-10-27，用户已拍板）

> 一句话：Tauri 球弃用 WebView2 改 **Win32 分层窗口 + 位图 alpha**（物理上零毛刺），Electron 球改 **超采样 alpha 位图**（浏览器内上限）；背景自适应白/黑；吸附扩为四边（上/下/左/右）就近择一。
> 用户明确：不要长篇汇报，直接按本文件逐项实施；毛刺要「彻底消除」，CSS 打补丁路线已被否定。

## 诊断结论（为什么以前修不好）

毛刺三源都在「浏览器 CSS 画圆」这条链上：① 透明窗上 `border-radius` 圆角裁剪的抗锯齿（Chromium 对白底合成再套 alpha 掩码 → 白边/毛刺）；② `filter: brightness()` 状态强制合成层、`radial-gradient` 渐变抖动；③ `translate(-50%,-50%)` + `top:50%` 在非 1/4 整数倍 DPI 下落到分数物理像素（阶梯毛刺）。v1.77b–v1.80 反复失败正是因为圆的边缘始终经过浏览器裁剪/合成管线。

## 改动项 1（根治）：Tauri 球 → 原生分层窗口（webview-app）

- 新建原生球窗实现（建议 `src/floatwin/native.rs`，替代 `window.rs` 的 WebView2 建窗）：`CreateWindowExW` + `WS_EX_LAYERED | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_TOPMOST`，`UpdateLayeredBitmap` 提交 **32bpp 预乘 ARGB** 位图。
- 位图内容：2×/4× 超采样画圆盘（平涂白/黑 + 1px 半透明描边）+ 叠加 `icons/icon.png`（PNG 解码：`png` 或 `image` crate / WIC）。圆的轮廓即位图 alpha —— **不再有任何 CSS/裁剪参与**。
- 命中：分层窗口天然按像素 alpha 穿透（alpha=0 自动透传点击）→ **退役** `WM_NCHITTEST` 子类化（shape.rs 大部分）、命中圆原子量、`live_offset` 活柱、WebView2 最小宽 hack、ball 数据目录。
- 鼠标交互进 WndProc：左键按下/移动/抬起 → 拖拽（阈值判定）与单击切换主窗；右键 → 关闭悬浮图标并唤回主窗；`WM_MOUSEMOVE`/`TrackMouseEvent` → 悬停展开 + 移开延迟缩回。
- 主题：读 `HKCU\...\Themes\Personalize\AppsUseLightTheme` 决定白/黑底盘，监听 `WM_SETTINGCHANGE`/`WM_DWMCOLORIZATIONCHANGED` 重绘。
- 退役（删干净）：Tauri 侧 `floaticon://` 球页注入、一次性令牌 + 8 个球事件 + capability（`float-icon.json`）中球页相关部分；`show_ball` 页面样式链。保留：设置页开关、tray、`FloatWinGeom` 落盘/恢复、dock 纯函数几何。
- ⚠️ 架构例外需登记：根 `AGENTS.md` §3.4.1 共用页面清单把 `floaticon.html` 改为 **Electron 专属**（仿 `mobilebar.js` 例外写法）。

## 改动项 2+1'：Electron 球 → 超采样 alpha 位图（共享页 `webview-app/src/floaticon.html`）

Electron 浏览器内无原生窗口，取「纹理 alpha 直通」上限：

- `#w2f-ball` 改为 canvas 超采样栅格化圆盘 data URL（平涂 + 描边，无渐变/无 filter/无 border-radius 边缘/无 transform/无 opacity），按 `devicePixelRatio` 物理像素对齐（`sizeDev=round(56*dpr)`，xDev 按 anchor='r' 取 `viewportDevW-sizeDev`，与 Rust/布局逐像素一致）。
- 自适应白/黑：`matchMedia('(prefers-color-scheme: dark)')` + change 监听，预渲染 idle/hover/collapsed 三套盘面变体换 `background-image`；hover 只微调内部 `img`（36→37px）。
- 保留契约字面量：`width: 56px; height: 56px;`、`left: 28px;`、`left: calc(100% - 28px);`、`background: transparent`、无 `<svg`、`src="icon.png"`、无 title、`translate(clientX, clientY)` 拖动协议、`screenX/screenY` 协议。
- 状态类：`w2f-dock-left/right` + 新增 `w2f-dock-top/bottom`、`w2f-collapsed`。

## 改动项 3：四边吸附（两壳）

- 语义：左/右沿 x 半隐藏，上/下沿 y 半隐藏（peek=28 逻辑像素），悬停展开/延迟缩回不变；`decide_edge` 四边**就近择一**（左/右须纵向重叠、上/下须横向重叠，多边入阈值取 |gap| 最小，治屏幕角歧义）。
- Rust `src/floatwin.rs`：`decide_edge` 扩四边；新增 `expanded_y` / `collapsed_y` / `clamp_x`（与 x 系对称）；`edge_str` 补 `'top'`/`'bottom'`。`src/floatwin/events.rs`（或原生化后的新模块）按轴分派贴边/钳制/缩回。`src/store.rs` `DockEdge` 增 `Top`/`Bottom`（serde 小写，旧数据缺省 → none 向后兼容）；`persist_geometry` 落盘展开态坐标（x/y=展开态左上角语义不变）。
- Electron `src/main/float-layout.ts`：`FloatEdge` 增 `'top'|'bottom'`；`expandedY`/`collapsedY`/`clampX`；`decideEdge` 就近择一；`planDrop`/`planPeekCollapse` 按轴分派；`parseFloatGeometry` 认识新值。`src/main/float-window.ts` expand/collapse/persist 按轴取坐标。
